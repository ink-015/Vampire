# 类吸血鬼幸存者 · 每日作战计划（第一版，14 天）

> 一句话：你在黑夜里一边跑位一边自动开火，杀掉成群怪物、捡经验，每次升级三选一，活过 10 分钟就算赢。

## 0. 这份计划怎么用

- 每天只推进**一格**，一格 = 一个能按 Play 看见变化的结果 = 一次提交。
- 每天的顺序固定：**先提交一次空改动（确认仓库是干净的）→ 学 20 分钟 → 写代码 → 跑通 → 提交**。
- 卡住超过 40 分钟就停下来记一条 issue，第二天再处理，不要一天耗在一个 bug 上。
- 时长按「每天 2 小时」估的（可改）。总量 14 天 ≈ 28 小时，其中写代码约 18 小时，学 git 约 3 小时，找素材与调平衡约 7 小时。

## 1. 三个分支怎么并成一条线

| 分支 | 它管什么 | 落在哪几天 | 每天产出什么 |
|---|---|---|---|
| ① 素材 | 找免费可商用的、生成占位图、替换、统一风格 | D0 已有占位图 → D10 换真素材 → D12 音效 | `Assets/Resources/Art/*.png` |
| ② 代码 | Unity 工程与 C# 玩法逻辑 | D1–D9 主线，D11 手感 | `Assets/Scripts/*.cs` |
| ③ Git | 每天提交、回滚、分支、上传 GitHub | 贯穿 D1–D14，每天一个动作 | 仓库历史 + README |

三条线不是三个文件夹，是**同一份工程上的三种动作**：写代码 → 提一次 → 顺手在素材目录放张图 → 再提一次。

## 3. 这一版明确砍掉的东西（不是以后不做，是这一版不做）

| 做法 | 具体是什么 | 为什么砍 |
|---|---|---|
| ❌ 多角色与角色解锁 | 3 个可选角色、各自天赋 | 第一版只需要 1 个角色证明循环成立 |
| ❌ 技能树 / 装备 / 商店 | meta 成长系统 | 单局循环没打磨好之前，meta 只是放大器，放大的是缺点 |
| ❌ BOSS 与关卡 | 分段地图、BOSS 阶段 | 需要额外 2 套状态机，收益低于把 10 分钟做扎实 |
| ❌ 存档与排行榜 | 本地存档、在线榜 | 需要后端与账号，超出「一个能玩的 demo」 |
| ❌ 联机 | 多人同屏 | 直接进入网络同步领域，不是第一版该碰的 |
| ❌ 自己写 Shader | 卡通渲染、描边 | 留到作品集第二阶段单独做一个 Shader 合集 |
| ✅ 保留：跑位 + 自动攻击 + 刷怪 | 核心循环 | 这是整个品类的骨架，必须自己写一遍 |
| ✅ 保留：经验与三选一 | 成长反馈 | 玩家愿意再来一局的原因 |
| ✅ 保留：对象池 | 性能手段 | 面试能讲 20 分钟的技术点 |
| ✅ 保留：结算与重开 | 完整闭环 | 「做完」比「做大」重要 10 倍 |

## 4. Git 学习曲线（每天 10 分钟，不单独开课）

| 天 | 只学这一个命令或概念 | 一句话解释 |
|---|---|---|
| D1 | `init` `add` `commit` `log` | 仓库 = 时间机器；commit = 存档点 |
| D2 | `.gitignore` | 不进仓库的文件写在这，Unity 的 Library 就是典型 |
| D3 | `status` `diff` | 提交前先看清楚自己改了什么 |
| D4 | `restore` | 改坏了退回上一次存档 |
| D5 | `branch` `checkout` `merge` | 分支 = 平行存档，做完再合并 |
| D6 | `stash` | 手头没写完，先临时收起来 |
| D7 | 冲突 | 两个人（或两个分支）改了同一行，手动选留哪句 |
| D8 | `tag` | 给「能玩的版本」钉一个钉子 |
| D9 | 提交粒度 | 一个功能一个提交，别一天一个巨型提交 |
| D10 | `CREDITS.md` | 素材来源与许可证也要进仓库 |
| D11 | `log --oneline --graph` | 用图看自己的历史 |
| D12 | `.gitattributes` | 告诉 git 哪些是二进制、别做行尾转换 |
| D13 | issue | 用 issue 当待办，比记在脑子里可靠 |
| D14 | `remote` `push` `Release` | 推到 GitHub，打 tag 出可玩包 |

## 5. 每天收工前的一句话自检

1. 今天按 Play，画面和昨天有什么不一样？（说不出 = 今天等于没做）
2. `git log -1` 这条提交信息，三个月后的自己看得懂吗？
3. 明天第一件事是哪一行代码？（说不出来 = 明天会先浪费 30 分钟）
